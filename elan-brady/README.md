# Élan Brady — The Vision

An interactive investor presentation for Élan Brady, a future Texas luxury
jewelry house. Plain HTML / CSS / JS — no build step. Open `index.html` in a
browser (or serve the folder) and click / arrow-key through.

- Opens with a short auto-playing film (skippable, tap to advance)
- Five Texas lines, the Crossroads connector system, Martha capsule,
  material tiers, production model, staged investment gates, revenue model
- All imagery lives in `assets/` (real design boards, renders and photography)
