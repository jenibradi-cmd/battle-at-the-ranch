The Relic Connector — one standard

Turquoise heishi base · wearer-swappable · one identical fitting serves single & span relics.

The base

Turquoise heishi strand with matched host points — CENTER · SIDE · SIDE. All host points are identical: a single relic uses one, a span relic bridges two.

Wear modes

  • Mode A — single relic on the CENTER point (e.g. pearl relic, diamond-eye stone relic).
  • Mode B — span relic bridging TWO points as fringe (Clip A + Clip B). Same clip as Mode A, used twice; graduated oxidized fringe with diamond drops.

The relic family

Every relic ends in the same clip, so any one fits any host point:

  • Baroque pearl
  • Coin medallion
  • Cross
  • Diamond-eye stone
  • Fringe (span)

Finish & scope

Oxidized silver with platinum-gray high points. Turquoise base leads; other bases (belt / scarf) are parked for now. Original design spec — concept line art.
